# 剑 / 箭囊 / 石磨 贴图重设计

> 作者：黑山大叔
> 主页：https://space.bilibili.com/19428259
> GitHub：https://github.com/heiheids

## 目标

原有贴图图案复杂、无用细节多。重新设计后要求：
平滑、有材质特点、不琐碎。**只改贴图，模型几何完全未动。**

## 设计要点

| 物品 | 材质表现 | 调色板规模 |
|---|---|---|
| 桃木剑 | 暖红木，6 段连续明暗模拟圆柱受光 | 11 色 |
| 雷击木剑 | 焦褐木 + 浅金高光 | 11 色 |
| 天罚雷击木剑 | 深灰木 + 冷银刃光 | 11 色 |
| 箭囊 | 皮革筒身 + 两道金箍 + 顶部开口 | 10 色 |
| 石磨盘面 | 同心圆磨纹 + 中央磨眼 + 四道放射槽 | 7 色 |

共同做法：**用连续明暗阶表现体积，不用噪点堆细节。**

## UV 区域（由模型决定，未改动）

剑类贴图 16×16 划分为四块：

| 区域 | 坐标 | 用途 |
|---|---|---|
| 剑身 | 0,0 – 6,11 | 刀刃与齿 |
| 护手 | 6,0 – 10,6 | guard |
| 握柄 | 10,0 – 14,6 | grip / pommel |
| 符纸 | 0,10 – 6,16 | talisman |

箭囊与石磨的 UV 都是整张 16×16。

## 重要修正：石磨贴图此前未被引用

原模型写的是：

```json
"stone": "minecraft:block/andesite"
```

也就是说 `textures/block/stone_mill.png` **从来没有被任何模型使用**，之前无论怎么改石磨贴图游戏里都看不到效果。

现已把 `stone_mill.json` 与 `stone_mill_upper.json` 的 `stone` / `particle` 指向自有贴图（**仅改贴图引用，几何未动**）：

```json
"stone": "jiangshidao:block/stone_mill",
"particle": "jiangshidao:block/stone_mill"
```

## 工具链

| 脚本 | 作用 |
|---|---|
| `tools/ops/redesign-textures.ps1` | 生成 5 张贴图（逐像素绘制，参数集中在调用处） |
| `tools/ops/render-3d-preview.ps1` | 真实纹理映射的 3D 效果图 |
| `tools/ops/render-texture-sheet.ps1` | 贴图平铺放大图（看单张图案） |

用法：

```powershell
pwsh -NoProfile -File tools\ops\redesign-textures.ps1
pwsh -NoProfile -File tools\ops\render-3d-preview.ps1
```

效果图输出到 `预览图\贴图重设计_真实纹理效果图.png`。

## 预览器演进（踩坑记录）

第一版预览器每个面只取 UV 区域**平均色**，结果把木纹、金箍、同心圆全部抹平成单一色块，
导致连续几轮误判「贴图不理想」。

第二版改为**逐像素纹理映射**：每个面细分成网格，按 UV 逐点采样贴图，
透明像素按 cutout 丢弃。这才真实反映游戏内观感。

结论：**渲染预览工具本身的保真度，直接决定设计判断是否可信。**
