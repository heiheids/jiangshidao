僵尸怪物模组（Jiangshi Zombie）— 模组使用说明
=================================================
作者:黑山大叔
主页:https://space.bilibili.com/19428259
github：https://github.com/heiheids

目标版本：Minecraft 1.21.1 / NeoForge（D:\1.21.1F-NF\.minecraft\versions\1.21.1-NeoForge）
当前进度：v0.1.0 —— 仅完成“怪物模型 + 3D 预览渲染”，尚未进入代码实现阶段。

-------------------------------------------------
一、本版本包含什么
-------------------------------------------------
1. 清代官服僵尸（Jiangshi）的完整方块模型，共 39 个盒子 / 234 个面：
   · 头部：僵尸绿方头、深陷黑眼窝、参差黄牙、方形耳
   · 官帽：黑色宽帽檐 + 红色帽顶 + 金色顶珠座 + 红色顶珠
   · 身体：石青缎面长袍、暗红前襟镶边、黑色腰带、胸前金框“补子”（仙鹤纹）
   · 手臂：双臂整体前伸 84°（经典僵尸姿势），袖口暗红镶边，双手三指下勾
   · 腿部：高筒黑靴，长袍下摆盖至靴口
2. 与参考图一致的配色（石青 #3F5A55 / 暗红 #762E38 / 僵尸绿 #6EA650 / 黑 #23262A / 金 #B8994C）。

-------------------------------------------------
二、如何查看 3D 渲染效果
-------------------------------------------------
方式一（直接看图，推荐）：
  打开 out\preview\ 目录：
   · preview_sheet.png   五视图拼版（正/四分之三/侧/背/面部特写）
   · 1-front.png / 2-three-quarter.png / 3-side.png / 4-back.png / 5-face.png  单视图
   · atlas.png           皮肤贴图图集（程序化生成）

方式二（自行重新渲染）：
  需要 Node.js 18 以上，无需联网、无需安装任何依赖：
    cd 工程目录
    node tools/render/render.js --size 1024
  生成结果输出到 out\preview\。
  · --size 控制画布边长（默认 1024）
  · 想改机位：编辑 tools\render\render.js 里的 VIEWS 数组（yaw 水平角、pitch 俯仰角）

-------------------------------------------------
三、如何修改外观
-------------------------------------------------
· 改模型形状/比例 → tools\model\model.js（每个部件都是一个 [min, max] 盒子）
· 改配色         → tools\art\palette.js
· 改贴图细节     → tools\art\texture.js（脸部、补子、布料分别有独立函数）

三个文件都是纯数据/纯绘制，改完直接重新渲染即可看到效果，无需编译。

五、注意事项
-------------------------------------------------
· 本版本不包含任何 .class / .jar，不能直接放进游戏，仅供预览确认造型。
· 所有临时文件、渲染产物都生成在工程目录内，未在工程外写入任何文件。
· 工程源码每次修改前都会自动备份到 备份\ 目录，记录见 某某工程备份.txt。
