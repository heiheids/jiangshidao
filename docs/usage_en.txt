Target: Minecraft 1.21.1 / NeoForge
Version: v0.1.0 — MODEL PREVIEW ONLY (no .jar yet)

-------------------------------------------------
1. What is in this version
-------------------------------------------------
A full blocky model of a Qing-dynasty-official zombie ("Jiangshi"),
built from 39 boxes / 234 faces:

  * Head: green zombie block head, sunken black eye sockets,
    uneven yellow teeth, square ears
  * Hat: wide black brim + red dome + gold finial base + red knob
  * Body: teal silk robe, dark-red front trim, black belt,
    gold-framed rank badge ("buzi") with a crane motif on the chest
  * Arms: BOTH arms extended forward at 84 degrees (classic zombie pose),
    dark-red cuffs, three hooked fingers per hand
  * Legs: tall black boots, robe hem covering the boot tops

Palette matches the reference image:
  teal #3F5A55 / dark red #762E38 / zombie green #6EA650
  black #23262A / gold #B8994C

-------------------------------------------------
2. How to view the 3D render
-------------------------------------------------
Option A — just look at the images (recommended):
  Open out\preview\:
    preview_sheet.png   five-view contact sheet
    1-front.png, 2-three-quarter.png, 3-side.png, 4-back.png, 5-face.png
    atlas.png           procedurally generated skin atlas

Option B — render it yourself:
  Requires Node.js 18+. No internet, no npm install, no dependencies.
    cd <project folder>
    node tools/render/render.js --size 1024
  Output goes to out\preview\.
    --size  canvas edge length (default 1024)
    Camera angles live in the VIEWS array in tools\render\render.js
    (yaw = horizontal angle, pitch = vertical angle)

-------------------------------------------------
3. How to change the look
-------------------------------------------------
  Shape / proportions  -> tools\model\model.js  (each part is a [min,max] box)
  Colors               -> tools\art\palette.js
  Texture details      -> tools\art\texture.js  (face, badge, fabric each
                          have their own function)

All three are plain data / plain drawing code. Edit, re-render, done.
