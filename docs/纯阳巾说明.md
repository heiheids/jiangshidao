# 纯阳巾（道冠）

> 作者：黑山大叔
> 主页：https://space.bilibili.com/19428259
> GitHub：https://github.com/heiheids

## 一句话说明

装备在模组自带饰品栏的**头部槽**，渲染在玩家头顶。需要长期佩戴（默认 **10 个游戏日**）才会显灵，显灵后提供三项能力。

## 三项能力

| # | 能力 | 说明 |
|---|---|---|
| 1 | 见鬼 | 可见 **25 格**内隐身的女鬼。**仅佩戴者可见**，其他玩家照旧看不见 |
| 2 | 加倍 | 佩戴者击杀亡灵时，**掉落物与经验各翻一倍** |
| 3 | 威慑 | 原版亡灵**不主动攻击**佩戴者；佩戴者先动手则它们照常还击 |

三项能力**都只对佩戴者生效**，且**都必须满 10 个游戏日**才激活。

## 合成

```
线  线  线
线  金锭 线      ← 外圈 8 个线，中心 1 个金锭
线  线  线
```

## 累计佩戴时长

- 存在**物品自身**的数据组件 `chunyang_wear` 上
- 换下再戴回进度不丢；把道冠交给别人，进度跟着物品走
- 每 **5 秒**写回一次并同步到客户端
- 物品说明里实时显示：`已佩戴 3.2 日 / 10 日（32%）`
- 满 10 日后显示：`十日期满，法力已成`

## 可调参数（启动参数，无需重新构建）

| 参数 | 默认 | 作用 |
|---|---|---|
| `-Djiangshidao.headwear.y=0.5` | 0.5 | 头顶高度。**调大上移、调小下移** |
| `-Djiangshidao.headwear.scale=0.55` | 0.55 | 道冠大小。**调大更大** |
| `-Djiangshidao.chunyang.activate=200` | 不设置 | 临时降低激活门槛（200 tick = 10 秒），**仅供验收，正式游玩不要加** |

启动时日志会打印实际生效值：

```
[渲染] 纯阳巾头顶渲染参数：y=0.5 scale=0.55
```

## 验收步骤（建议加 `-Djiangshidao.chunyang.activate=200`）

1. 创造栏取「纯阳巾」，确认图标正常（不是紫黑方块）
2. 拖入饰品栏**头部槽**，头顶应出现道冠
3. 戴上后等 10 秒，物品说明应变为「十日期满，法力已成」
4. 找一只女鬼：25 格内可见；取下道冠后不可见
5. 打一只僵尸：掉落两份、经验两倍
6. 站在僵尸旁不动：它不主动攻击；你打它一下：它反击

## 已知限制

- 开发环境无法运行（26.3 无 intermediary 映射，Fabric API 的 classTweaker 命名空间不匹配），只能构建后部署到真实安装目录验证
- 「仅佩戴者可见」是通过客户端渲染覆盖实现的，服务端的隐身标志不变
